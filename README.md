# CRM Чат-центр — Telegram Bot

Полноценная CRM-система для чат-центра, управляемая через Telegram-бота.

## Возможности

### Для операторов
- Создание обращений (имя, телефон, контакт, источник трафика, описание)
- Изменение статусов: Новый / В работе / Оплачен / Отменён / На паузе
- Фиксация оплат с суммой и комментарием
- Указание причины отмены
- Добавление клиентов в Green / White / Black List
- Поиск обращений по имени, телефону, контакту
- Просмотр своих обращений

### Для руководителей (Supervisor / Admin)
- Все возможности оператора
- Отчёты за день / вчера / неделю / месяц / произвольный период
- Аналитика по операторам (конверсия, количество обращений)
- Аналитика по источникам трафика
- Журнал всех действий
- Управление операторами (смена ролей)
- Управление источниками трафика

## Быстрый старт

### 1. Скопируйте .env файл
```bash
cp .env.example .env
```

### 2. Заполните .env
```
BOT_TOKEN=токен_вашего_бота (получить у @BotFather)
ADMIN_IDS=ваш_telegram_id (через запятую, если несколько)
POSTGRES_USER=crm_user
POSTGRES_PASSWORD=надёжный_пароль
POSTGRES_DB=crm_db
TIMEZONE=Europe/Moscow
```

### 3. Запустите через Docker
```bash
docker-compose up -d
```

### 4. Проверьте логи
```bash
docker-compose logs -f bot
```

## Стек технологий
- **Python 3.11** + **aiogram 3** — Telegram бот
- **PostgreSQL 16** — база данных
- **SQLAlchemy 2.0** (async) — ORM
- **Docker + docker-compose** — деплой

## Роли пользователей
| Роль | Возможности |
|------|-------------|
| Operator | Обращения, поиск, оплаты, списки |
| Supervisor | + Отчёты, аналитика, журнал, управление |
| Admin | + Все права Supervisor |

Первый пользователь из `ADMIN_IDS` автоматически получает роль **Admin**.

## Структура проекта
```
├── bot/
│   ├── handlers/       # обработчики команд бота
│   ├── keyboards/      # inline-клавиатуры
│   ├── middlewares/    # авторизация
│   ├── states/         # FSM состояния форм
│   └── main.py         # точка входа
├── database/
│   ├── models.py       # модели SQLAlchemy
│   ├── crud.py         # CRUD-операции
│   └── connection.py   # подключение к БД
├── integrations/
│   └── teletype.py     # заглушка для Teletype (раскомментировать при наличии API)
├── docker-compose.yml
├── Dockerfile
└── .env.example
```

## Интеграция с Teletype App
Архитектура готова к подключению Teletype App. Когда получите API-ключ:
1. Добавьте `TELETYPE_API_KEY` в `.env`
2. Раскомментируйте код в `integrations/teletype.py`
3. Добавьте webhook-эндпоинт

## Команды бота
- `/start` — регистрация / главное меню
- `/skip` — пропустить необязательное поле при создании обращения
