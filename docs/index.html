полная инструкция

crm-бот чат-центра

здесь описаны все возможности бота: от регистрации до настройки системы. разделы с пометкой sv доступны только супервайзерам и администраторам.

🚀 регистрация и первый запуск

при первом обращении к боту система автоматически создаёт учётную запись оператора.

как начать
1
найдите бота в telegram
откройте telegram и перейдите по ссылке, которую прислал администратор.
2
нажмите ▶ start
бот запросит у Вас имя и фамилию из профиля telegram. если данные не указаны — попросит ввести их вручную.
3
учётная запись создана
вы получите роль «оператор». для получения роли «супервайзер» обратитесь к администратору.
💡 если бот не отвечает — возможно, администратор ещё не добавил Вас в список разрешённых пользователей. уточните у него.

👥 роли пользователей

в системе три уровня доступа. каждый следующий включает все возможности предыдущего.

👤
оператор
создаёт и ведёт обращения, работает с клиентами, видит отчёты по своей работе.
🛡️
супервайзер
видит всю аналитику, журнал действий, управляет справочниками системы и ролями операторов.
👑
администратор
полный доступ. назначается при первом запуске через переменную окружения ADMIN_IDS.
ℹ️ сменить роль оператора может только супервайзер или администратор через «управление системой → смена роли».

➕ создание обращения

нажмите «➕ новое обращение» в главном меню. бот последовательно запросит у Вас данные.

8 шагов создания
1
номер телефона клиента
введите номер в любом формате, например +79001234567 или 89001234567. при совпадении с базой система автоматически определит статус клиента.
2
контакт (имя или ник)
имя в мессенджере, никнейм или любое другое обозначение клиента.
3
источник трафика
выберите из списка или нажмите «➕ новый источник» для добавления нового.
4
персонаж (модель)
выберите персонажа из списка, введите нового или нажмите «пропустить», если неизвестно.
5
мастер (исполнитель)
выберите мастера, который проводит сеанс, введите нового или пропустите.
6
длительность сеанса
введите число минут (например, 60) или нажмите «пропустить».
7
описание / комментарий
дополнительные заметки об обращении. можно пропустить.
8
подтверждение
бот покажет сводку всех данных. нажмите «✅ подтвердить» для сохранения или «✏️ изменить» для редактирования.
💡 на любом шаге можно нажать «отмена», чтобы вернуться в меню без сохранения.

🔄 статусы обращения

статус отражает этап жизненного цикла обращения. менять статус может оператор, создавший его.

все статусы
статусзначениеособенности
новый обращение только что создано стартовый статус
в работе оператор ведёт переговоры —
оплачено клиент оплатил сеанс —
отменён клиент отказался бот запросит причину отмены
уход клиент ушёл без завершения бот запросит причину ухода
на удержании клиент думает, ждёт —
⚠️ при выборе статусов «отменён» и «уход» бот обязательно спросит причину. введите её текстом — это важно для отчётности.

🎯 результат обращения

результат — итоговая категоризация обращения. указывается дополнительно к статусу в любой момент.

результаткогда применяется
позитивный лид клиент заинтересован, есть высокая вероятность записи
бронь клиент официально забронировал сеанс
общий лид первичный контакт, интерес не подтверждён
💡 чтобы указать результат, откройте карточку обращения и нажмите 🎯 указать результат.

💳 оплата

к одному обращению можно добавить несколько платежей разных типов.

оплата сеанса
основная оплата за проведённый сеанс.
оплата за отмену
штраф или компенсация при отмене брони.
консумация
оплата услуг или дополнений во время сеанса.
доп. время
оплата дополнительного времени. бот дополнительно запросит у Вас количество минут.
процесс добавления оплаты
1
в карточке нажмите 💳 добавить оплату
2
выберите тип оплаты
сеанс / отмена / консумация / доп. время
3
если выбрано «доп. время» — введите количество минут
4
введите сумму
5
введите комментарий (или пропустите)
оплата появится в карточке обращения и в ежедневной выгрузке.

🔍 поиск обращений

позволяет найти любое обращение независимо от того, кто его создал.

что искать
  • по номеру телефона — введите телефон клиента (полностью или частично)
  • по id обращения — введите числовой идентификатор, например 42

результаты показываются списком. нажмите на нужное обращение, чтобы открыть его карточку.

📌 мои обращения

раздел показывает только те обращения, которые вы создали. удобно для ежедневной работы.

откройте «📌 мои обращения» в главном меню. бот покажет список всех ваших обращений в хронологическом порядке (последние — первые). нажмите на любое, чтобы открыть карточку.

📓 списки клиентов

система ведёт три списка клиентов по номеру телефона. при создании обращения статус определяется автоматически.

три списка
списоккто попадаетприоритет
зелёный / белый проверенные клиенты, с которыми работать можно средний
чёрный нежелательные клиенты высший — перекрывает белый
автоматическое определение статуса

при создании нового обращения система проверяет телефон клиента по спискам:

  • если телефон в чёрном списке → статус клиента «чёрный список»
  • если телефон в белом списке → статус «белый список»
  • иначе → «новый»
ручное добавление в список

откройте «📓 списки клиентов», выберите нужный список и нажмите «➕ добавить». введите номер телефона и, при желании, комментарий.

📊 отчёты

раздел показывает сводную статистику за выбранный период. доступен всем операторам.

периоды отчётов
сегодня вчера эта неделя этот месяц за всё время
что показывает отчёт
  • общее число обращений за период
  • распределение по статусам: новые, в работе, оплачены, отменены, уходы, на удержании
  • причины отмены — список с количеством (у супервайзера)
  • причины ухода — список с количеством (у супервайзера)
  • суммы по типам оплат: сеанс, отмена, консумация, доп. время
  • общая сумма поступлений

📈 аналитика операторов sv

сравнительная таблица эффективности каждого оператора за выбранный период.

что отображается по каждому оператору
  • имя и фамилия оператора
  • количество созданных обращений
  • количество оплаченных, отменённых, ушедших
  • конверсия в оплату
ℹ️ раздел доступен только пользователям с ролью «супервайзер» и выше.

📡 аналитика трафика sv

показывает, сколько обращений пришло из каждого источника, и какая конверсия в оплату.

что показывает
  • список источников трафика
  • количество обращений по каждому источнику
  • количество оплат по источнику
  • конверсия (оплаты / обращения)

📜 журнал действий sv

хронологический лог всех значимых изменений в системе.

что фиксируется
  • создание нового обращения
  • смена статуса обращения
  • добавление оплаты
  • изменение результата
  • добавление клиентов в списки
  • смена ролей операторов
  • добавление справочников (источники, модели, мастера)

каждая запись содержит время события, имя оператора и описание действия.

⚙️ управление системой sv

справочники и настройки, которые администратор или супервайзер ведут вручную.

список операторов

показывает всех зарегистрированных пользователей: имя, никнейм telegram и текущую роль.

смена роли оператора
1
нажмите «сменить роль»
2
введите telegram id оператора
оператор может найти свой id у @userinfobot.
3
выберите новую роль
оператор или супервайзер
персонажи (модели)

откройте «управление → персонажи». здесь отображается список всех моделей. для добавления нажмите ➕ добавить персонажа и введите имя.

мастера

аналогично. «управление → мастера» → ➕ добавить мастера.

источники трафика

«управление → источники трафика» → ➕ добавить источник. также источник можно добавить прямо в процессе создания обращения.

🌐 язык интерфейса

бот поддерживает два языка интерфейса — русский и английский.

в главном меню нажмите 🌐 язык. выберите 🇷🇺 русский или 🇬🇧 english. изменение применяется сразу и сохраняется между сессиями.

📤 ежедневная excel-выгрузка

каждый день в 10:00 бот автоматически формирует и отправляет в указанный telegram-чат файл excel со всеми обращениями за предыдущий рабочий день.

рабочий день в выгрузке

период: с 10:00 предыдущего дня до 10:00 текущего дня. например, файл за понедельник охватывает промежуток пн 10:00 → вт 10:00.

особенности файла
  • первая строка зафиксирована — при прокрутке заголовки остаются видны
  • встроенная фильтрация по любой колонке (кнопки ▼ в заголовках)
  • чётные строки выделены цветом для удобства чтения
  • если обращений за день нет — бот пришлёт текстовое уведомление
⚙️ для получения выгрузки администратор должен добавить переменную EXPORT_CHAT_ID в настройки сервера — telegram id чата, куда бот будет присылать файл.

если у Вас возникли вопросы — обратитесь к администратору системы.
